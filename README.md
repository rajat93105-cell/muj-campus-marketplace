# MUJ Marketplace

A full-stack campus marketplace built for Manipal University Jaipur students.

## Features
- JWT Authentication
- Image Upload (Cloudinary)
- Advanced Filtering & Search
- Seller Dashboard with Analytics
- Soft Delete & Product Status
- Wishlist
- Real-Time Chat Between Users

## Tech Stack
Frontend: React + Tailwind + Recharts  
Backend: Node.js + Express + MongoDB  
Media: Cloudinary  
Auth: JWT  

## Run Locally

Backend:
```bash
cd backend
npm install
npm run dev
```

Frontend:
```bash
cd frontend
npm install
npm run dev
```
